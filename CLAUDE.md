# Conventions

- **Code in English**: identifiers, functions, variables, file names, comments, test names, docs.
- **UI text in PT-BR**: anything the user reads in the app (labels, buttons, placeholders, user-facing error messages).
- **Commits:** English, [Conventional Commits](https://www.conventionalcommits.org/) — `feat:`, `fix:`, `chore:`, `refactor:`, `test:`, `docs:`.
- **Branching:** git flow — `main` (releases), `develop` (integration), `feature/*`, `release/*`, `hotfix/*`.
- Commit only when asked.
